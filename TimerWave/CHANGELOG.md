# Changelog

## 1.0.0
- Initial release of TimerWave for Fabric 1.21.11.
- Player timer with start/stop/pause/resume/reset and per-world persistence.
- Countdown with set/start/stop/reset/status.
- Countdown completion blinks red (no sound) and uses top blue bossbar progress.
- Runtime style and color preset selection.
- Multiplayer support with per-player server-side state.
